# 📊 InsightAI

InsightAI is an AI-powered Business Intelligence Assistant that helps users analyze business data using artificial intelligence.

## Features

- Upload CSV/Excel files
- Automatic data cleaning
- Interactive dashboard
- AI-powered insights
- Business recommendations
- Sales forecasting

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
- Google Gemini API
